# Customer Churn Prediction & LLM Feedback Analysis

A technical case study on synthetic automotive-service data: predicting which customers are likely to stop visiting the service network, and evaluating how reliably an LLM can label Turkish customer feedback.

> The dataset was provided by a third party and is **not included** in this repository. To rerun the code, place the four source CSV files in a `veri/` folder at the repository root (see `teslim/README.md` for the exact steps). `teslim/ciktilar/musteri_analiz.csv` is regenerated by `analiz.py`.

## What was done

**1. Churn prediction**
- Built a customer-level analysis table (recency, frequency, monetary) from four joined sources, with explicit data-quality decisions (duplicates, negative amounts, feedback dated before purchase).
- Observation window 2022-01-01 to 2025-06-30, target window 2025-07-01 to 2026-06-30: 3,315 returning vs 658 churned customers (16.6%).
- Regularized logistic regression with a customer-level stratified 60/20/20 split; threshold chosen on validation only.
- Test ROC-AUC 0.753 (95% CI 0.709-0.798) vs 0.500 baseline; average precision 0.454 vs 0.166.
- Leakage control: CRM status fields and undated contact notes were excluded after they were found to leak the target.

**2. LLM text labeling and evaluation**
- 200 randomly sampled Turkish feedback comments labeled by an LLM for sentiment and topics.
- Compared against a 40-record human-labeled gold set: 92.5% sentiment accuracy (macro-F1 0.919) and 82.5% exact topic match (micro-F1 0.937).
- Systematic errors identified: mixed sentiment collapsed to one pole, over-tagged topics from generic praise, and empty/meaningless text.
- Prompt refined from these findings: sentiment 95.0%, topic exact match 92.5% on the same set.
- Guardrails proposed so LLM-generated agent actions cannot promise unapproved offers (allowed-action list, templated sentences, human approval).

**3. Review of a flawed draft report**
- Critiqued a draft analysis and flagged 10+ issues, including target leakage, misread p-value, causal overreach, and mismatched counts.

## Limitations (also stated in the report)
- The prompt-refinement result is a development comparison on the same 40 records, not an independent or blind test; the gold set has 25 unique texts and a single labeler.
- Model versions between labeling rounds were not verified to be identical.
- Single cut-off date and synthetic data: production performance would need external validation, calibration, and a small controlled pilot.

## AI usage
An AI coding assistant and an LLM were used for code and labeling; the full usage log, prompts, and a documented case where the tool was wrong are in `teslim/RAPOR.md` (section 5) and `teslim/ciktilar/llm_kullanim_gunlugu.txt`.
